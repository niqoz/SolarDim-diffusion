# SolarDim — installateurs Windows et Linux

Téléchargez la dernière version dans [Releases](https://github.com/niqoz/SolarDim-diffusion/releases/latest) :

- **Windows** : `SolarDim-<version>.msi` (ou le `.exe`, équivalent), puis lancez-le.
- **Linux** (Debian 13, Ubuntu 24.04 et suivantes) : le fichier `.deb`, puis
  `sudo apt install ./<fichier>.deb`. Le paquet Linux accompagne les Releases
  à partir de la 0.1.627.

Empreintes SHA-256 : `SHA256SUMS.txt` (Windows) et `SHA256SUMS-linux.txt` (Linux).

Le code source n'est pas publié ici.
